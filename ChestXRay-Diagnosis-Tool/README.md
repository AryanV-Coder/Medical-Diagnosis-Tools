# ChestXRay Diagnosis Tool

An AI-powered diagnostic assistant for radiologists. The system ingests a patient's Chest X-ray, classifies it for **Cardiomegaly**, **Pleural Effusion**, and **Pneumothorax** using a fine-tuned DenseNet-121, generates a Grad-CAM heatmap highlighting regions of interest, and drafts a structured clinical report via a RAG-augmented LLM.
